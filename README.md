# Ravex Agents

This is a personal agents orquestator, you can use it for testing or for personal use

## Requirements

- [Bun](https://bun.sh) 1.3.14 or later

## Getting started

```sh
bun install
bun run dev
```

Press `q` or `Ctrl+C` to quit the app. In `bun run dev`, `q` only closes the app and the file watcher keeps running, so press `Ctrl+C` to stop it.

## Scripts

| Command | Description |
| --- | --- |
| `bun run dev` | Run the app and restart it when files change |
| `bun run start` | Run the app |
| `bun test` | Run the tests |
| `bun run typecheck` | Type-check the project |
